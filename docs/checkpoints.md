## Изменения требований

**Кейсы портфолио**
- Было: 4 проекта из репозитория (GLASS, 33 наклейки, Пром-Материалы, BMW/DAV).
- Стало: 8 работ из портфолио greenboxweb.ru — Клиника Ткачева, THE CASE, учебный центр «Перспектива», Happy Kids, YPM Group, Центр кранового оборудования, СДЭК-калькулятор, Rubber Department. GANG AUTO исключён — сайт отдаёт 404.
- Почему: решение пользователя на интервью 29.09.2026. Поля «Задача» и «Результат» по каждому кейсу остаются видимыми заглушками — этих данных нет ни в репозитории, ни на сайте.

**Отзывы**
- Было: рабочее предположение «взять с сайта как есть».
- Стало: агент при разборе сайта отметил признаки шаблонности (компании в отзывах не совпадают ни с одним кейсом портфолио, у одного отзыва цифра «+150%» без опоры на кейс) → пользователь подтвердил, что отзывы реальные → переносим 4 отзыва дословно, аватары — инициалы.
- Почему: прямое подтверждение пользователя перевешивает подозрение агента; источник — реальные клиенты студии, а не шаблонный контент.

**Шрифт заголовков**
- Было: Space Grotesk + Onest (первичный выбор).
- Стало: Unbounded (заголовки) + Onest (текст).
- Почему: проверка показала, что у Space Grotesk нет кириллицы — на старом сайте русские заголовки фактически рисовались шрифтом Inter (подмена). Для нового сайта это не годится, выбран Unbounded с поддержкой кириллицы.

**Визуальное направление**
- Было: раунд 1 выдал случайный вариант «Адресное хранение» (склад, ячейки с адресами), альтернатива Impeccable — «Пульт управления»; заказчик отклонил оба и дал установку (уникально, просто, воздух, премиум, аккуратность) → раунд 2 выдал «Маршрут» (схема линии метро), альтернатива Impeccable — «Паспорт изделия»; заказчик попросил не выбирать по тексту, а увидеть варианты вживую.
- Стало: собран прототип трёх живых вариантов («Маршрут», «Паспорт изделия», «Стандарт категории»); заказчик выбрал «Стандарт категории» — канон e-commerce-студии на уровне референсов брифа, без удешевлений.
- Почему: решение пользователя по живому прототипу, 29.09.2026. Зафиксировано в `PRODUCT.md` (Brand Commitments) и в контракте направления `.impeccable/surfaces/site-src-app-page-tsx.md`.

**Поля по бокам**
- Было: не заданы — ни в брифе, ни на интервью.
- Стало: 100 px на десктопе.
- Почему: уточнение заказчика при выборе направления «Стандарт категории», 29.09.2026.

**Фон первого экрана**
- Было: не было в плане — hero задумывался как UI витрины и админки, собранный в коде, без фонового изображения.
- Стало: добавлено фоновое изображение под затемнением; кандидатов (5–6, с лицензиями Unsplash/Pexels) готовит агент «Фото для hero» в `assets/source/hero/`, выбирает заказчик.
