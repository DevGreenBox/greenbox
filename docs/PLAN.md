## Решения интервью (29.09.2026)

**Процесс**
- Идём по брифу полностью: 8 этапов, после каждого checkpoint, два агента документации.
- Остановка на согласование одна: выбор визуального направления в этапе 4. Остальное без остановок.

**Бренд и факты**
- Название «ЗелёнаяКоробка».
- Логотип визуально 1:1 с текущим сайтом: Inter 800, двухцветный, переведён в SVG. Favicon (лаймовый куб) оставляем как есть.
- Источник фактов: бриф плюс офферы сайта («макет за 24 ч бесплатно», скидка 60% клиентам СДЭК). Срок «2–2,5 недели» берём из брифа.

**Структура**
- 10 блоков брифа плюс блок «Команда».
- «Стать партнёром» ведёт на `https://greenboxweb.ru/partner.html`.
- Текста мало, копирайт пишу я строго по фактам.

**Контент**

| Что | Решение |
|---|---|
| Hero | UI магазина и админки, собран в коде и анимирован |
| Кейсы | 8 работ из портфолио greenboxweb.ru (GANG AUTO убран: сайт отдаёт 404). Картинки `ff*.jpg` со старого сайта. Описание идёт в «Что сделали», поля «Задача» и «Результат» — видимые заглушки |
| Отзывы | 4 отзыва с сайта дословно. Реальность подтвердили вы. Аватары — инициалы, как на сайте |
| Команда | Дробышев И.С. (основатель), Нестеров А.С. (старший веб-разработчик). Фото с сайта |
| Контакты | info.greenboxweb@gmail.com, Telegram @infogreenbox, реквизиты ИП из /legal.html |
| Квиз | 5 шагов, затем сразу форма. Ответы уходят вместе с заявкой |
| Формы | Чекбокс согласия по 152-ФЗ и страница /privacy. Текст политики — заглушка, своего текста нет |

**Визуал**
- Палитра greenboxweb.ru 1:1, светлая и тёмная.
- Добавки:
  - затемнённый зелёный для мелкого текста (ради WCAG AA);
  - циан #00E5FF в одном градиенте hero.
- Темы: переключатель плюс чередование светлых и тёмных сцен. В тёмной теме сцены контрастные: либо глубже фона, либо на зелёной заливке.
- Шрифты self-host:
  - заголовки — Unbounded (у Space Grotesk нет кириллицы, проверено);
  - текст — Onest.
- Анимации среднего уровня:
  - pinned-секции, горизонтальный скролл кейсов, маски на тексте;
  - своя хореография для мобильных;
  - поддержка `prefers-reduced-motion`.

**Техника**
- Next.js 16 (Node-сервер), Tailwind 4, GSAP + CSS.
- Заявки идут в Telegram-бота через route handler. Токен и chat_id лежат в env; пока их нет, заявки пишутся в лог.
- Разработка только локально. Мета-теги настраиваем под `https://greenboxweb.ru`. Аналитики нет (её не было и на старом сайте); тег `yandex-verification` сохраняем.
